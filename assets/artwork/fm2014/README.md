# Original Freshmind artwork

These are byte-for-byte copies from the root of the author's Java reference checkout, `../knowceans/knowceans-freshmind-2014/`. The reference directory has no Git metadata, so no upstream commit is asserted. [manifest.json](manifest.json) records original filenames, byte counts and SHA-256 hashes. No images were regenerated or edited.

| Artwork | Original exports | Editable source | Reference use |
| --- | --- | --- | --- |
| Freshmind icon | [GIF](freshmind.gif), [PNG](freshmind.png) | [PSD](freshmind.psd) | Browser window and file dialogs; 64 × 64 |
| Freshmind splash | [GIF](fmsplash.gif) | [PSD](fmsplash.psd) | Startup splash; 368 × 298 |
| Arbylon icon | [GIF](arbylon.gif) | [PSD](arbylon.psd) | Annotation editor windows; 64 × 64 |
| Graph background | [JPEG](background.jpg) | [PSD](background.psd) | Legacy TouchGraph panel background; 600 × 400 |

The PSD files preserve the original editable documents, including whatever layers and palette information each original contains. These assets are kept in the repository; the browser does not load them automatically and the npm package does not include this archive.
