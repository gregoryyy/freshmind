## 10. Retrieve by inferred topics

## 12. Retain a negative judgment

**Search**

Rejecting a selected green result relation removes that link and saves its source, target, query, engine and corpus provenance. Repeating the same query omits that item. ## 13. Remove a query and keep the source graph

**Search**

![Remove a query and keep the source graph](13-search-delete-query.png)

Select the LDA text-query node and press Ctrl+Backspace (or Ctrl+Delete) while graph focus is active. Only that query and its incident associations disappear; retrieved papers, original semantic relations, the earlier tag query and the paper-based similarity search remain. Native YAML can retain the queries and rejection judgments you choose to keep.

## 35. Edit labels and weights together

**Editing and keyboard**

![Edit labels and weights together](35-label-weight.png)

F2 opens a graph-anchored label overlay with weight controls for either a node or a relation. Ctrl+G/H adjusts the shared draft; a numeric suffix such as Graph browsers =3 also sets absolute weight on Save. The draft leaves the graph unchanged until committed; Escape cancels both label and weight.

## 36. Edit node details directly in an overlay

**Editing and keyboard**

![Edit node details directly in an overlay](36-details-editor.png)

Ctrl+Enter commits the weight. Ctrl+Space or Shift+F2 then opens the full modeless editor at the node annotation, outside the side pane. It also exposes types, visual settings, URLs and metadata. Close retains a per-item draft; Save commits and Escape cancels. The annotation shown here is still a draft.

## 37. Point at the graph to control its center

**Editing and keyboard**

Close the editor, clear selection and move the pointer over a branch without clicking. Keyboard control resumes at the node in the viewport center, independently of the hovered branch. Enter acts immediately on that centered target; arrow navigation then continues from the selected node.

## 38. Explicit control focus takes priority

**Editing and keyboard**

![Explicit control focus takes priority](38-control-focus.png)

Focus Graph spacing in the side pane, then point back at the graph. The input keeps focus and Enter belongs to that control. Editors, buttons and summaries have the same protection. Click or Tab into the graph when ready to return keyboard control.

## 39. Suppress oscillation with or without RFC

**Layout motion**

![Suppress oscillation with or without RFC](39-layout-damping.png)

View → Layout motion enables general adaptive damping by default. It watches all movable visible nodes, including when RFC is off as shown here. Adaptive impulses attenuates repeated swings and gradually restores gain; Earlier TouchGraph cooling instead starts the inherited fast cooling phase after detected cycles. The status makes the active setting visible.
