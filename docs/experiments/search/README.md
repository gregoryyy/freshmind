## Protocol

The fictional topic library has 24 nodes and 28 semantic relations: eighteen papers, three researchers, two layout/topic bridge papers and one collection root. Text deliberately separates graph layout, probabilistic topic models and forest ecology. The complete graph is the search corpus; even the root and people are indexed. The fixture is newly authored, with no legacy corpus or external URL extraction.

Six two-word term queries and three existing-paper similarity queries use predefined binary relevance sets. A theme's papers and researcher are relevant; both bridge papers are relevant for layout and topics. The collection root is irrelevant. Similarity removes the source from its relevance set. These broad synthetic judgments are explicit fixture assumptions, not human relevance annotations. Query words occur in training text; there is no held-out evaluation claim.

Lexical queries use OR between words and the documented TF–IDF/cosine rules. LDA trains three topics for 200 serial sweeps with alpha 0.1, beta 0.01 and seeds 4357, 7, 13, 41, 2027. Each text query folds in for 50 sweeps with an independent chain reset to that model's seed; existing-node similarity uses theta directly. All runs use the same sorted corpus and vocabulary. LDA similarity is 1−JSD/log(2). Layout, visibility, RFC and lens settings do not enter retrieval scores.

Precision@5 counts relevant items divided by five, including missing-result slots as misses. Recall@5 divides by the full case relevance set. Reciprocal rank is measured within the first five. Each LDA table entry averages five seed runs; the range shows their precision variation. Seeds are not independent datasets or statistical confidence intervals. Lexical is run once per case (9 runs), LDA five times per case (45 runs).

## Interpretation and limits

This checks a reproducible end-to-end retrieval path on deliberately separated synthetic topics. The table reports the observed scores, including seed-dependent topic failures; it does not establish that LDA improves real search. Lexical ranking is strong when query words are present. Bayesian topic inference can join related vocabulary, but short queries, small corpora and bridge documents can mix topics, and increasing training passes does not guarantee better results. Inspect all model topic words and rankings before interpreting a seed's result. No hyperparameter tuning or seed selection was performed to remove poor runs.

The browser walkthrough demonstrates query/context/result links, exact tags, topic words, node similarity and persisted rejection feedback separately from these numerical judgments. Feedback is collected, not used to train these models. No original 2005 figures or proprietary Java datasets are reproduced.

## Reproduce

`just search-example` regenerates native data. `just search-experiment` rebuilds the library and replaces only this experiment's report and records. Pass `--output DIRECTORY` for an independent replay; the JSON and Markdown should be byte identical. `just search-flipbook` captures the production browser. The optional `just test-lda-java` checks the pinned serial Java sampler and RNG reference.
