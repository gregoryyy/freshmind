# RFC membership example

[trees-and-dag.fm.yaml](trees-and-dag.fm.yaml) is synthetic and generated by [scripts/substructure-examples.mjs](../../../scripts/substructure-examples.mjs), using `just substructure-examples`. It contains 12 nodes and 13 semantic relations.

- `tree-example`: seven members, six selected relations, depth two.
- `dag-example`: six members, six selected relations, a shared descendant and four ranks (0–3).
- `shared` belongs to both definitions. The ordinary `context` relation belongs to neither.

In the browser choose **Load example → Trees and DAG**, expand **Reinforcement Focus + Context → Substructures**, select a definition and press **Reinforce substructure**. Activating the second retains the first. Shift+Enter or Shift+double-click toggles an independent one-hop center. The **RFC centers** selector can remove one activation; **Remove RFC** clears all activation without deleting definitions.

The file restores memberships rather than active RFC state. Shared members balance competing constraints, so label overlap and region interference remain possible. See the [model/layout/clustering design](../../rfc-substructures.md) for API, force semantics and current limits. This is a loadable functional example, not a reconstruction of a 2005 figure or a new quantitative result in the draft paper.

## Weighted tree

[weighted-tree.fm.yaml](weighted-tree.fm.yaml) is generated by the same recipe and available as **Load example → Weighted tree**. It has seven nodes and six relations in a saved tree. Node `a` has importance nine and relation `ra` has importance thirty. Node `c` and relation `aa2` have zero importance. Activate **Weighted tree** in Substructures: all semantic records remain, while five nodes and four relations receive RFC halos. Edit Weight to compare added stiffness. See the [importance contract](../../rfc-importance.md). This is a functional example, not an additional paper experiment.
