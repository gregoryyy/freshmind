# Fictional workspace graph

[workspace.fm.yaml](workspace.fm.yaml) is an original synthetic graph under the
project license: six nodes, thirteen directed relations, one zero-weight parallel
relation, a reciprocal pair, loops and cross-links. It supports the
[radius-two browser walkthrough](../../docs/radius-two-browser.md).

The labels describe fictional software components; the generic weights are FM
importance values, not measured calls, costs or dependency strengths. This is
an interaction fixture. The public dependency-impact pilot and comparative
evaluation remain separate roadmap tasks.
